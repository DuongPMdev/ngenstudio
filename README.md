# NGen Portfolio Website

Static responsive website built with HTML, CSS and vanilla JavaScript from the provided `NGen Portfolio 2025.pptx`.

## Run locally
- Open `index.html` in a modern browser, or
- Run a local static server from this folder, for example: `python -m http.server 8000`, then visit `http://localhost:8000`.

## Before publishing
1. Replace `hello@ngen.games` in `index.html` with the official company email.
2. Confirm the company name, partner naming, team names/roles, project descriptions and public-facing wording.
3. Add the official company domain and analytics/SEO metadata if needed.
4. Upload the folder contents to your web hosting. No build step is required.

## Notes
- Game test metrics were omitted from this public-facing version.
- The hero uses selected gameplay images extracted from the supplied presentation.
- Fonts are loaded from Google Fonts; fallback fonts are provided if offline.
